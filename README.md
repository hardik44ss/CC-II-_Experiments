# CC-II Lab Mastery

> An interactive DSA learning studio for exploring algorithms, visualizing execution, and practicing implementation in the browser.

[![React](https://img.shields.io/badge/React-19-61DAFB?logo=react&logoColor=white)](https://react.dev/) [![TypeScript](https://img.shields.io/badge/TypeScript-5-3178C6?logo=typescript&logoColor=white)](https://www.typescriptlang.org/) [![Vite](https://img.shields.io/badge/Vite-8-646CFF?logo=vite&logoColor=white)](https://vite.dev/)

## ✨ What You Can Do

- Learn through **10 guided DSA experiments**.
- Watch algorithms run with interactive visualizers.
- Explore concepts, pseudocode, invariants, and Big-O complexity.
- Write solutions in **C++, Java, Python, or JavaScript**.
- Run test cases directly in the browser.
- Track completed labs and saved code with browser storage.

<details>
<summary>📚 Topics Covered</summary>

- Searching and array operations
- String manipulation
- Sliding window
- Insertion and Shell sort
- Merge sort and Quick sort
- Greedy algorithms
- Queues and deques
- Dynamic programming and tries

</details>

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## 🧭 Learning Flow

1. **Learn & Visualize** — understand the idea with step-by-step animations.
2. **Code & Verify** — implement the solution and run automated tests.
3. **Track Progress** — complete experiments and review your lab report.

## 🛠️ Tech Stack

React · TypeScript · Vite · Tailwind CSS · Motion · Lucide Icons

## 📁 Main Folders

- `src/components` — reusable interface and learning components
- `src/components/visualizers` — algorithm visualizations
- `src/data` — experiment definitions and test cases
- `src/utils` — code execution helpers
